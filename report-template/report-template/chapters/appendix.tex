\section{Appendix}

\subsection{Setup and Run Instructions}
The DataSanitizer project is designed for straightforward local deployment on modern Windows, macOS, or Linux systems with Python 3.10+ installed.

\begin{lstlisting}[language=bash,caption={Local setup commands for Windows PowerShell.},label={lst:setup}]
# 1. Clone repository from GitHub
git clone https://github.com/nuan2779/DataSanitizer.git
cd DataSanitizer

# 2. Create and activate Python virtual environment
py -3.11 -m venv .venv
.\.venv\Scripts\activate

# 3. Install core dependencies
pip install -r requirements.txt

# 4. Ensure local staging directories exist
New-Item -ItemType Directory -Force -Path '.\data\raw', '.\data\processed' | Out-Null

# 5. Launch Back-end Server (Terminal 1)
python -m uvicorn backend.main:app --reload --port 8000

# 6. Launch Front-end Static Server (Terminal 2)
python -m http.server 5500 -d frontend
\end{lstlisting}

Once both servers are running:
\begin{itemize}
  \item Web Application Interface: \url{http://127.0.0.1:5500/index.html}
  \item Interactive OpenAPI (Swagger) Documentation: \url{http://127.0.0.1:8000/docs}
\end{itemize}

\subsection{Verification and Test Execution}
To verify the complete mathematical integrity and API contract compliance of the project, execute the automated test suite using \texttt{pytest}:

\begin{lstlisting}[language=bash,caption={Automated test execution command.},label={lst:testrun}]
pytest tests -v
\end{lstlisting}

The test harness evaluates 19 distinct unit and integration test scenarios across 6 test modules, confirming that all endpoints, validators, and transformation pipelines execute with zero failures.

\subsection{Use of Artificial Intelligence (AI) Tools}
In compliance with academic integrity guidelines established by the Faculty of Data Science and Artificial Intelligence (NEU), the team explicitly declares the utilization of AI assistance during project execution:
\begin{itemize}
  \item \textbf{Antigravity AI (Google DeepMind):} Employed as an interactive pair-programming assistant for debugging regex boundary edge-cases in currency string parsing, advising on two-tier defensive type validation in JavaScript, assisting in generating edge-case Pytest unit tests, and structuring the report within the institutional \texttt{fdareport.cls} XeLaTeX template.
  \item \textbf{Verification and Authorship:} All algorithmic logic, architectural designs, API implementations, and written analytical content were reviewed, verified, tested, and validated by the team members. No AI-generated hallucinated content or unverified external code was incorporated into the production codebase.
\end{itemize}
